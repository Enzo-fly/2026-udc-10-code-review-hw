# Рев'ю pr-4: PR-4: Винести хелпери дат у src/dates.js

**Вердикт:** Можна зливати
**Знахідок:** 0 (critical: 0, high: 0, medium: 0, low: 0)

## Знахідки

Знахідок немає. Перевірено:

- `toUtcMs`, `daysBetween`, `addDays` у `app/src/dates.js` (рядки 6–16) збігаються з базовими `toUtc`, `daysBetween`, `addDays` з `app/src/loans.js` (рядки 8–18) за логікою: та сама розбивка рядка `YYYY-MM-DD`, `Date.UTC`, `Math.round`, `toISOString().slice(0, 10)`; константа `MS_PER_DAY = 86_400_000` дорівнює базовому літералу `86_400_000`. Межі, округлення й знак різниці не змінено (К5, К10).
- `loans.js` імпортує й реекспортує `addDays`, `daysBetween` (`app/src/loans.js:2-4`), тож наявний імпорт у `app/test/loans.test.js:4` (`addDays, daysBetween` з `../src/loans.js`) і виклики в `borrow`, `lateFee`, `overdueReport` працюють без змін.
- Перейменування `late` → `daysLate` у `lateFee` (`app/src/loans.js:28-29`) не змінює обчислення.
- Нова експортована функція `toUtcMs` і новий модуль описані в `app/CHANGELOG.md` (К6).
- Нові тести в `app/test/dates.test.js` перевіряють конкретні значення через `assert.equal` (перехід через кінець місяця й року, від'ємна різниця, UTC-північ) — кожен упав би на неправильній реалізації (К8). Наявні тести не змінено.
